# ToDo App (Java Console Project)

A simple console-based To-Do application written in Java.  
This project was created to practice basic programming concepts such as loops, conditionals, lists, user input, and object-oriented thinking.

---

## 🚀 Features
- Add new tasks
- List all tasks
- Exit the program
- Stores tasks in an in-memory ArrayList

---

## 🧠 What I Learned
- How to use loops (`while`)
- Getting user input with (`Scanner`)
- Managing lists using (`ArrayList`)
- Basic control flow (`if / else if / else`)
- Structuring a simple Java application

---

## 🛠️ Technologies Used
- **Java**
- **ArrayList**
- **Scanner**
- Console-based user interaction

---

## ▶️ How to Run
1. Open the folder containing `ToDoApp.java`
2. Compile the code:
   ```
   javac ToDoApp.java
   ```
3. Run the program:
   ```
   java ToDoApp
   ```
